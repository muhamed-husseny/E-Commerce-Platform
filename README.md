# E-Commerce Platform

A feature-rich, modern e-commerce platform built with Asp.Net Framework. This project provides a complete online shopping experience, from browsing products to completing orders.


Features
- User Authentication: Secure login and registration functionality with JWT token-based authentication.
- Password Management: Full password lifecycle including forgot password, reset password via email token, and change password for authenticated users.
- Product Catalog: Browse products by brand and category, with search, sorting, and filtering capabilities.
- Shopping Cart: A fully functional shopping cart powered by Redis for real-time basket management.
- Multi-Step Checkout: A guided checkout process with address entry, delivery method selection, payment, and order review.
- Order History: Users can view their past orders with detailed information and status tracking.
- Delivery Methods: Multiple shipping options with different costs and estimated delivery times.
- Email Notifications: SMTP-based email service for sending password reset links and notifications to users.
- Product Image Upload: Upload product images with file format and size validation.
- User Address Management: Save and update shipping addresses linked to user profiles with auto-fill during checkout.
- Pagination & Caching: Server-side pagination with client-side caching for efficient data retrieval.
- Error Handling: Global error handling with dedicated error pages and structured API error responses.

  
## Tech Stack

- ASP.NET Core Web API  
- Entity Framework Core (EF Core)  
- SQL Server  
- AutoMapper
